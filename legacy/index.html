PENGATURAN AKUN & RISIKO

📈 KOMPOUNDING

🎯 SETUP MODE SNIPER (bidikan entry)

⚙ LEVERAGE & TIME-STOP PER GAYA

AUTO memilih leverage agar jarak SL ≈ 1×ATR (di luar noise). Manual bebas 2–25x dengan guard likuidasi: pada SL struktural (Simons), leverage dipangkas otomatis bila SL > 50% jarak likuidasi. Time-stop: posisi ditutup otomatis bila TP1 belum tersentuh dalam N candle TF entry — tercatat "TIME" di Quant Log.

🤖 AUTO-PILOT (robot server — eksekusi otomatis di testnet)

AUTO-PAPER 📝: scanner mencatat setiap sinyal valid (semua mode & gaya) sebagai posisi paper ke jurnal via cloud — tanpa exchange, pengumpul data 24 jam; aplikasi mengimpor & memonitornya (biarkan tab PC hidup utk cakupan penuh). AUTO ⚡: eksekusi sungguhan ke exchange demo. Rem terpasang: kill-switch harian −5%, maks 2 posisi, 6 trade/hari, cooldown 2 SL beruntun, 1 pair 1 posisi. Laporan entry masuk via Telegram. Saklar ini ikut sync — robot membacanya dari cloud. 🧪 RISET v18.9: saat robot AKTIF (paper/auto), scanner JUGA mencatat sinyal near-miss (Sniper 7/8, Simons 5/6) & sinyal luar-window sebagai posisi RISET terpisah — tidak memengaruhi saldo, rekap, maupun rem harian; murni bahan evaluasi per indikator/jam/hari.

🔔 NOTIFIKASI SINYAL KE HP

Syarat: aplikasi terbuka (boleh di background/layar mati, jangan ditutup penuh). Saat mode Sniper/Simons ON dan sebuah pair berubah jadi VALID → HP bergetar + notifikasi berisi pair, arah, harga & skor — ketuk untuk langsung membuka aplikasi. Anti-spam: pair yang sama maks 1 notifikasi per 15 menit.

⚡ EKSEKUSI REAL — TESTNET/DEMO

Belum terhubung. PIN disimpan hanya di perangkat ini (tidak ikut sync).

🧬 SETUP SIMONS MODE (mean reversion — rezim sideways)

Simons Mode = kebalikan Sniper: hanya aktif saat pasar SIDEWAYS (ADX rendah) dan harga stretched jauh dari mean — lalu fade kembali ke SMA20. SL struktural (ekstrem ± 0.25×ATR) dengan sizing dinamis: margin dihitung mundur agar risk tetap sesuai %.

☁ SINKRONISASI SEMUA PERANGKAT (otomatis)

Setup 3 menit (sekali saja): buka jsonbin.io → daftar gratis → Create Bin → isi {} lalu Save → salin BIN ID dari URL dan X-Master-Key dari menu API Keys → tempel di atas → set Aktif → Simpan Pengaturan → klik ⬆ Push sekali. Data tersimpan di bin privat milikmu sendiri.

Sinyal: EMA 9/21 · RSI 14 · MACD histogram · volume spike · VWAP(30), dihitung dari candle tertutup (data Binance public API). Skor ≥ +3 LONG KUAT, ≤ −3 SHORT KUAT. Plan entry: SL selalu di Net −10% ROE; jumlah TP mengikuti kekuatan sinyal — skor ±2 → TP1 (+20% ROE), ±3 → TP1–TP2 (+20/+40%), ±4 → TP1–TP3 (+20/+40/+60%), ±5 → TP1–TP4 (+20/+40/+60/+100%), semua net setelah fee, dengan porsi exit bertahap dan SL digeser ke breakeven setelah TP1. JEJAK MFE/MAE: selama posisi hidup, monitor merekam puncak ROE (MFE) dan palung ROE (MAE) beserta menit kejadiannya; tampil live di tab POSISI (↑/↓) dan tersimpan saat close. Evaluasinya: trade SL/TIME dengan MFE ≥15% = profit nyaris TP1 yang lolos (pertimbangkan TP lebih dekat/trailing); pemenang dengan MAE ≤ −7% = entry telat/kejar harga (nyaris SL sebelum jalan). Kondisi pasar saat entry (ADX, ATR%, RVOL, Z, sesi) sudah terekam berdampingan di baris yang sama. LEVERAGE ADAPTIF: mode AUTO memilih leverage agar jarak SL ≈ 1×ATR; guard likuidasi memangkas leverage bila SL struktural > 50% jarak likuidasi. TIME-STOP: posisi ditutup otomatis (alasan "TIME") bila TP1 belum tersentuh dalam N candle TF entry; badge ⏳ tampil sejak 50% umur. RVOL = volume candle ÷ rata-rata 20 candle (>1.5 spike, <0.8 kering/rawan fakeout — warning, bukan penolak). CHoCH = break minor swing melawan arah sinyal dlm 6 candle (peringatan dini, dicatat di log). MODE SIMONS (mean reversion): kebalikan sniper — hanya aktif saat ADX < batas (sideways) dan |Z-score| ≥ batas (harga stretched dari SMA20), dikonfirmasi RSI ekstrem + candle pembalikan + tanpa momentum volume searah stretch; SL struktural di ekstrem 10-candle ± 0.25×ATR, TP1 setengah jalan ke mean (50%) dan TP2 di mean (50%), margin DINAMIS dihitung mundur dari jarak SL agar risk % tetap. Grade dicatat "MR" dan mode terekam di Quant Log untuk perbandingan EV Sniper vs Simons. MODE SNIPER: hanya meloloskan setup dengan 8/8 kondisi — bias EMA timeframe atas (M1→M15, M5→H1, M15→H4, H1→H4, H4→D1) searah, skor ≥±3, SMC Grade A+, ADX ≥23 (pasar trending, anti-chop), RSI HTF belum exhausted, momentum MACD searah, BTC tidak melawan (untuk altcoin), dan berada di window WIB (untuk TF scalping). Tombol entry terkunci jika ada satu saja kondisi gagal; kartu valid tampil paling atas dengan bingkai emas. Harga entry, SL, dan seluruh tangga TP diperbarui live per detik via WebSocket Binance; analisis indikator & SMC dihitung ulang otomatis mengikuti timeframe (mode Auto: M1 tiap 15 dtk, M5 30 dtk, M15 60 dtk, H1 2 mnt, H4/D1 5 mnt). Indikator 📍 Status entry membandingkan harga live dengan harga saat sinyal terbentuk (dalam ×ATR) dan memperingatkan agar tidak mengejar harga yang sudah lari. Deteksi SMC otomatis (BOS, sweep, OB, FVG, premium/discount) bersifat heuristik dari data candle — checklist jurnal terisi otomatis saat mencatat dari sinyal, tapi tetap verifikasi visual di chart. Tombol "Catat ke Jurnal" pada kartu sinyal mengisi form otomatis (pair, arah, entry, SL 1×ATR) — kamu tinggal isi hasil exit setelah trade selesai. Data jurnal tersimpan otomatis di perangkat ini dan bisa di-export ke CSV untuk dibuka di Excel. QUANT LOG merekam konteks pasar (skor, grade, SMC, ADX, ATR%, Z-score, korelasi BTC 30-bar, drift entry, sesi, TF, mode TP) pada momen entry dan hasilnya saat close — bucket EV dihitung per kondisi; abaikan bucket dengan sampel <30. Grade sinyal: checklist SMC/ICT (BOS, sweep, OB, FVG, premium/discount) — ≥3 cek = A+, 1–2 = A, 0 = B; emosi FOMO/Balas Dendam/Overtrade = NO-TRADE. Alat bantu analisis, bukan saran finansial.
