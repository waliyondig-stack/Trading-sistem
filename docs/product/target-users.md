# Target Pengguna

FlowNiaga dirancang agar dapat diadopsi bertahap oleh:

| Segmen              | Kebutuhan utama                                              | Fase relevan |
| ------------------- | ------------------------------------------------------------ | ------------ |
| Usaha mikro         | Pencatatan sederhana, POS, stok dasar                        | 1–4          |
| UMKM                | Omnichannel dasar, CSV import, laporan harian                | 2–5          |
| Bisnis multi-cabang | Branch scope, approval, konsolidasi laporan                  | 1, 7         |
| Distributor         | Gudang banyak, transfer stok, pricing bertingkat             | 3, 8         |
| Online seller       | Marketplace sync, reconciliation pembayaran                  | 4–5          |
| Bisnis jasa         | Work order, booking (industry pack)                          | 8            |
| Perusahaan menengah | RBAC granular, audit, workflow approval                      | 1, 7         |
| Enterprise          | Multi-legal-entity, SSO, analytics warehouse, data retention | 9            |

## Persona MVP (Fase 1–4)

1. **Pemilik (Owner)** — mendaftar, mengundang tim, memantau dashboard, menyetujui tindakan berisiko.
2. **Manajer cabang** — mengelola operasional cabang dan gudang dalam scope-nya.
3. **Kasir** — transaksi POS/pesanan manual; akses baca terbatas.
4. **Staf gudang** — penerimaan, fulfillment, adjustment stok (dengan approval untuk yang besar).
5. **Finance** — pencatatan pembayaran, reconciliation, laporan.
6. **Auditor** — akses baca menyeluruh tanpa hak ubah.

## Karakter UX

Modern, sederhana, profesional, tepercaya, mobile-first, bahasa Indonesia, tidak terasa seperti ERP rumit — namun tetap menopang kebutuhan enterprise.
