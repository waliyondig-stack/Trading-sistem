🧬 SETUP SIMONS MODE (mean reversion — rezim sideways)

Simons Mode = kebalikan Sniper: hanya aktif saat pasar SIDEWAYS (ADX rendah) dan harga stretched jauh dari mean — lalu fade kembali ke SMA20. SL struktural (ekstrem ± 0.25×ATR) dengan sizing dinamis: margin dihitung mundur agar risk tetap sesuai %.

☁ SINKRONISASI SEMUA PERANGKAT (otomatis)

Belum tersinkron.
Setup 3 menit (sekali saja): buka jsonbin.io → daftar gratis → Create Bin → isi {} lalu Save → salin BIN ID dari URL dan X-Master-Key dari menu API Keys → tempel di atas → set Aktif → Simpan Pengaturan → klik ⬆ Push sekali. Di perangkat lain: masukkan ID & Key yang sama → ⬇ Tarik. Setelah itu semuanya otomatis: setiap perubahan (trade, posisi, setting) ter-push, dan setiap kali aplikasi dibuka data terbaru ter-pull. Data tersimpan di bin privat milikmu sendiri.

🔄 PINDAH PERANGKAT MANUAL (tanpa cloud)

Backup mencakup: pengaturan, seluruh jurnal, daftar token, dan POSISI yang sedang termonitor. Kirim file JSON-nya ke perangkat lain (WhatsApp/email/drive), lalu Restore di sana. Restore MENIMPA data perangkat tujuan.
Di leverage 20x, pergerakan ~5% melawan posisi = likuidasi. Batas loss harian adalah rem utama kamu — kalau tersentuh, berhenti trading hari itu.
Sinyal: EMA 9/21 · RSI 14 · MACD histogram · volume spike · VWAP(30), dihitung dari candle tertutup (data Binance public API). Skor ≥ +3 LONG KUAT, ≤ −3 SHORT KUAT. Plan entry: SL selalu di Net −10% ROE; jumlah TP mengikuti kekuatan sinyal — skor ±2 → TP1 (+20% ROE), ±3 → TP1–TP2 (+20/+40%), ±4 → TP1–TP3 (+20/+40/+60%), ±5 → TP1–TP4 (+20/+40/+60/+100%), semua net setelah fee, dengan porsi exit bertahap dan SL digeser ke breakeven setelah TP1. Kolom ×ATR menunjukkan seberapa realistis target vs volatilitas saat ini. ☁ SINKRONISASI: dengan Bin ID + Key yang sama di semua perangkat, jurnal, pengaturan, dan posisi termonitor otomatis identik — setiap perubahan ter-push (jeda 2 dtk), setiap buka aplikasi ter-pull. Monitor TP/SL tetap hanya berjalan di perangkat yang halamannya sedang terbuka; jalankan satu perangkat sebagai monitor aktif pada satu waktu agar jurnal tidak ganda. 📱 CATATAN HP: buka file ini dengan browser penuh (Chrome/Safari/Firefox), BUKAN preview di dalam aplikasi chat/file manager — preview memblokir koneksi data. Jika ISP memblokir binance.com (umum di beberapa operator Indonesia), aplikasi otomatis berpindah ke mirror api1/api2/api3 lalu data-api.binance.vision; jika WebSocket ikut terblokir, harga live otomatis beralih ke mode polling 3 detik (lihat label di status atas). Layar HP mati/aplikasi di-background akan menjeda update — buka kembali dan sistem menyambung ulang otomatis. Jika semua tetap gagal, jaringan Anda memblokir total: gunakan VPN atau jaringan lain. MODE SIMONS (mean reversion): kebalikan sniper — hanya aktif saat ADX < batas (sideways) dan |Z-score| ≥ batas (harga stretched dari SMA20), dikonfirmasi RSI ekstrem + candle pembalikan + tanpa momentum volume searah stretch; SL struktural di ekstrem 10-candle ± 0.25×ATR, TP1 setengah jalan ke mean (50%) dan TP2 di mean (50%), margin DINAMIS dihitung mundur dari jarak SL agar risk % tetap. Grade dicatat "MR" dan mode terekam di Quant Log untuk perbandingan EV Sniper vs Simons. MODE SNIPER: hanya meloloskan setup dengan 8/8 kondisi — bias EMA timeframe atas (M1→M15, M5→H1, M15→H4, H1→H4, H4→D1) searah, skor ≥±3, SMC Grade A+, ADX ≥23 (pasar trending, anti-chop), RSI HTF belum exhausted, momentum MACD searah, BTC tidak melawan (untuk altcoin), dan berada di window WIB (untuk TF scalping). Tombol entry terkunci jika ada satu saja kondisi gagal; kartu valid tampil paling atas dengan bingkai emas. Harga entry, SL, dan seluruh tangga TP diperbarui live per detik via WebSocket Binance; analisis indikator & SMC dihitung ulang otomatis mengikuti timeframe (mode Auto: M1 tiap 15 dtk, M5 30 dtk, M15 60 dtk, H1 2 mnt, H4/D1 5 mnt). Indikator 📍 Status entry membandingkan harga live dengan harga saat sinyal terbentuk (dalam ×ATR) dan memperingatkan agar tidak mengejar harga yang sudah lari. Deteksi SMC otomatis (BOS, sweep, OB, FVG, premium/discount) bersifat heuristik dari data candle — checklist jurnal terisi otomatis saat mencatat dari sinyal, tapi tetap verifikasi visual di chart. Tombol "Catat ke Jurnal" pada kartu sinyal mengisi form otomatis (pair, arah, entry, SL 1×ATR) — kamu tinggal isi hasil exit setelah trade selesai. Data jurnal tersimpan otomatis di perangkat ini dan bisa di-export ke CSV untuk dibuka di Excel. QUANT LOG merekam konteks pasar (skor, grade, SMC, ADX, ATR%, Z-score, korelasi BTC 30-bar, drift entry, sesi, TF, mode TP) pada momen entry dan hasilnya saat close — bucket EV dihitung per kondisi; abaikan bucket dengan sampel <30. Grade sinyal: checklist SMC/ICT (BOS, sweep, OB, FVG, premium/discount) — ≥3 cek = A+, 1–2 = A, 0 = B; emosi FOMO/Balas Dendam/Overtrade = NO-TRADE. Alat bantu analisis, bukan saran finansial.
